# 蓝云网盘 BlueCloudDrive（BCD）

基于 **Cloudflare Worker + D1** 的轻量网盘分享系统：后端只有一个 `_worker.js`，前端是同目录下的静态资源，
浏览器上传压缩包即可部署，首次访问自动建表，无需任何外部依赖与构建步骤。

- 存储：Cloudflare D1（专表专用，7 张业务表，首次启动自动建表 + 初始化默认配置 + 创建总管理员）
- 后端：`_worker.js`（路由、鉴权、参数校验、分享、下载统计、备份恢复）
- 前端：原生 HTML / CSS / JS（无框架、无打包），明亮 / 暗黑 / 跟随系统三套主题统一风格

## 二、部署（推荐：Cloudflare Pages 直接上传压缩包）

1. **创建 D1 数据库**
   控制台 → `Workers 和 Pages` → `D1 SQL 数据库` → `创建数据库`，名称例如 `bcd`。

2. **打包项目**
   在本目录执行 `pack.ps1`（右键 → 使用 PowerShell 运行），得到 `BlueCloudDrive.zip`。
   也可以直接右键整个 `BlueCloudDrive` 文件夹 → 压缩为 zip（**不要把文件夹本身压缩进去，zip 根目录必须能直接看到 `_worker.js`**）。

3. **创建 Pages 项目并上传**
   控制台 → `Workers 和 Pages` → `创建` → `Pages` → `上传资产` → 项目名例如 `blueclouddrive` → 上传上一步的 zip。

4. **绑定 D1（关键）**
   项目 → `设置` → `函数` → `D1 数据库绑定` → `添加绑定`：
   - 变量名称 **必须是 `DB`**（区分大小写，后端固定读 `env.DB`）
   - D1 数据库：选择第 1 步创建的库
   保存后 **重新部署一次**（Deployments → 重新部署），让绑定生效。

5. **访问并初始化**
   打开 `https://<项目名>.pages.dev`，首次访问 Worker 会自动建表并写入默认配置。
   进入 `/admin`，用初始总管理员账号 **admin / admin123** 登录，**立刻**在「账号设置 → 我的账号」里修改密码。

6. **绑定自定义域名（pan.domain.com）**
   Pages 项目 → `自定义域` → 添加 `pan.domain.com`（按提示修改 DNS）即可。
   全站链接都是**相对路径**，复制 / 展示分享链接时会自动使用访客当前访问的域名，因此**无需在后台配置域名**，D1 中也不保存域名。

> 想换数据库 / 重置系统：删除 D1 中的 `bcd_` 开头的表（或删库重建），再次访问即可重新初始化。

## 三、部署（备选：wrangler 部署 Workers + 静态资源）

```bash
npm i -g wrangler
wrangler d1 create bcd            # 把返回的 database_id 填进 wrangler.toml
wrangler deploy
```

`wrangler.toml` 里已经写好 `main = "_worker.js"`、`[assets] directory = "."`、`binding = "DB"`，
配合 `.assetsignore` 避免把 `_worker.js`、`_test/`、`pack.ps1` 等当成静态文件发布。
Worker 会处理 `/api/*`、`/s/*`、`/sf/*`、`/admin`、`/files`，其余请求直接由静态资源返回。

## 四、路由一览

| 路由 | 说明 |
| --- | --- |
| `/` | 主页（站点名称、可编辑简介、Markdown 公告、版权入口） |
| `/admin` | 管理员后台（未登录时为登录页） |
| `/files` | 所有文件浏览界面（管理员看到根目录 `/`，访客看到允许的根目录） |
| `/s/<分享编号>` | 单文件分享页：直接展示文件全部信息与操作按钮，不显示文件列表 |

| `/api/*` | 后端 JSON 接口（`/api/site`、`/api/files/list`、`/api/share/...`、`/api/admin/...`、`/api/dl/...`） |

## 五、功能说明

### 1. 账号角色与权限

| 角色 | 可做的事 |
| --- | --- |
| 总管理员 `total` | 全部权限：文件与全局设置、账号列表（新建 / 改密 / 禁用 / 删除）、导入导出、日志查看与清空 |
| 子管理员 `sub` | 文件管理、全局设置、修改自己的密码；**看不到**账号列表、日志与导入导出 |
| 用户 `user` | 只能浏览管理员指定目录（「用户根目录」，默认 `/文件分享`）并下载文件；有独立界面（左侧只有「账号设置」和「所有文件」），可修改自己的密码 |
| 未登录访客 | 由「对未登录访客开放文件浏览」开关控制，可看范围限定在「未登录访客根目录」，只能下载与搜索（若允许） |

在账号列表里改密必须输入**你当前登录账号**的密码；任何账号都能在「账号设置 → 我的账号」用原密码修改自己的密码。
在后台左侧菜单最下方「退出登录」。

### 2. 管理员后台（`/admin`）
左侧可折叠菜单（折叠状态记忆在浏览器）：

- **全局设置**：站点名称；**主页简介**（纯文本，一行）与**主页公告**（Markdown，留空则主页不显示公告模块，可预览 / 恢复默认文案）；
  **所有文件浏览权限**分「未登录访客」（开关 + 根目录）与「用户」（根目录）两组；
  是否允许搜索（默认允许）、是否统计下载次数（默认统计）。
  > 分享链接不落库也不配置域名：页面跳转全部使用相对路径，复制 / 展示链接时自动读取当前访问域名。
- **系统信息**：版本号、初始化时间、管理员账号数、用户账号数、文件数、当前登录、项目地址（GitHub 链接）与**检查更新**
  （调用 GitHub API 查询最新 Release：有新版本时弹窗展示版本号、
  更新说明与 Release 链接）。
- **账号设置**：修改本人昵称 / 密码；总管理员可新建**子管理员**与**用户**、改密、禁用/启用、删除。
- **文件分享列表**：所有分享文件按新到旧平铺展示，可搜索、可排序、可分页；
  每张卡片显示类型图标（未知类型使用 `simple.svg`）、文件名、路径、大小、分享时间、下载次数、密码与地址数量徽标；
  点击卡片或「编辑」可修改**全部设定项**。
- **所有文件**：新标签页打开 `/files`。
- **备份 / 恢复**（仅总管理员）：导出 / 导入前弹窗选择类别 —— **文件** / **设置** / **文件和设置** / **日志**
  （导入时没有「日志」选项；前三个类别都不含日志）。选中类别后可勾选附加选项：
  - 含「文件」时：`下载次数（默认不勾选）`、`文件简介（默认勾选）`
  - 含「设置」时：`账号列表（默认不勾选）`、`主页简介和标题（默认不勾选）`

  导入会覆盖所选类别（文件类别为整体覆盖，设置类别按条目更新）。日志区域展示最近操作日志并支持**一键清空**。

### 3. 新增 / 编辑分享文件
| 字段 | 规则 |
| --- | --- |
| 文件名称 | 必填；不能包含 `\ / : * ? " < > |` 等字符；≤128 字符 |
| 文件路径 | 必填，默认 `/文件分享`；自动创建不存在的各级文件夹（最多 12 级）；右侧「浏览…」可弹窗浏览全部文件夹，支持新建文件夹、右键删除空文件夹，选中后自动填入 |
| 文件地址 | 必填，可添加多个（≤20）：**直链**（http/https，直接下载）或**站外分享链接**（必须填写来源，点击后在新标签页打开，来源以蓝色标签展示） |
| 文件大小 | 默认「未知」；也可选择 B / KB / MB / GB 输入，最多 4 位整数 + 2 位小数 |
| 文件简介 | 默认空；支持 Markdown，≤2000 字符；不为空时在该文件的分享界面展示 |
| 下载密码 | 默认无；最长 10 个字符（可随时修改 / 清除） |
| 分享日期 | **后端提交时自动写入北京时间（精确到分钟）** |

任何一项不合法都会在对应输入框下方给出提示且**拒绝提交**（前端预校验 + 后端强制校验）。

### 4. 所有文件浏览界面（`/files`）
- 类资源管理器的文件网格 / 列表视图（可切换并记忆），文件夹在前、文件在后，按类型显示图标。
- 面包屑导航、上一级、刷新、排序（名称 / 时间 / 大小 / 类型 / 下载次数，升降序）、搜索、下载、删除。
- **所有文件操作都在右键菜单中**：打开、下载、复制分享链接、复制路径、查看下载地址；
  管理员额外拥有：编辑文件设定、移动到…、删除文件、复制文件夹分享链接、新建子文件夹、删除空文件夹。
- 单击文件跳转到它的分享链接 `/s/<编号>`，单击文件夹进入该目录。
- 管理员从根目录 `/` 开始；用户从「用户根目录」、未登录访客从「未登录访客根目录」开始，**都无法越权到上级目录**，
  且只有下载 / 搜索（若允许）权限。

### 5. 主页与分享页
- **主页 `/`**：站点名称、可编辑的简介（`home_desc`）与公告模块（`home_notice`，Markdown 渲染，留空则不显示），
  关闭未登录访客浏览后，访客看不到「进入所有文件」按钮。
- **单文件分享 `/s/<编号>`**：展示图标、文件名、大小、分享时间、下载次数、所在目录、密码状态，
  以及**文件简介**（Markdown，为空时不显示）和每个下载地址的按钮（直链→下载，站外链接→新标签页打开）。
  设置了密码时先输入密码解锁。
- **文件夹分享 `/sf/<编号>`**：展示该文件夹内容，每行右侧有「下载 / 详情」按钮；
  只有一个下载地址时点击即下载（直链）或打开（站外），多个地址时弹出选择框（站外来源以蓝色标签展示）；
  若文件设置了密码则先弹出密码框。支持面包屑下钻与（允许时的）搜索。

### 6. 主题
右上角可切换 **明亮 / 暗黑 / 系统**（默认跟随系统），选择记忆在浏览器本地，
所有页面共用 `css/style.css`。

## 六、数据库表结构（专表专用，前缀 `bcd_`）

| 表 | 用途 | 关键字段 |
| --- | --- | --- |
| `bcd_settings` | 全局设置（键值对：站点名、主页简介、主页公告、未登录访客开关与根目录、用户根目录、搜索开关、下载统计、会话签名密钥、初始化时间） | `key`(PK) `value` `updated_at` |
| `bcd_admins` | 账号（`total` 总管理员 / `sub` 子管理员 / `user` 普通用户） | `username`(UNIQUE) `password_hash` `salt` `role` `status` `last_login_at` |
| `bcd_sessions` | 登录会话 | `token`(PK) `admin_id` `expires_at` `ip` `user_agent` |
| `bcd_folders` | 文件夹（由文件路径自动创建，每个文件夹都有独立分享编号） | `path`(UNIQUE) `parent` `share_id`(UNIQUE) |
| `bcd_files` | 分享文件 | `share_id`(UNIQUE) `name` `folder` `path` `ext` `size_bytes` `size_text` `description` `password_hash` `download_count` `created_at` `updated_at`，`UNIQUE(folder,name)` |
| `bcd_links` | 文件的下载地址（一个文件多条） | `file_id` `kind`(direct/external) `url` `source` `sort_order` |
| `bcd_downloads` | 下载记录（统计用） | `file_id` `link_id` `kind` `ip` `country` `user_agent` `created_at` |
| `bcd_logs` | 操作日志（仅保留最近 50 条，不记录「用户」操作与文件创建 / 修改） | `actor` `action` `target` `detail` `ip` `created_at` |

- 所有建表语句都是 CREATE TABLE IF NOT EXISTS，在每次冷启动时执行一次，老库升级也不会丢数据；ALTER TABLE ... ADD COLUMN 会自动为老库补上后加的列（如 description）。
- 分享密码与管理员密码均以 `SHA-256(salt + 密码)` 存储，不保存明文。
- 分享链接解锁后签发带 HMAC 签名的临时令牌（2 小时有效），带密码的文件通过 `/api/dl/...` 下载时会校验令牌。

## 八、常见问题

1. **打开页面提示「未绑定 D1 数据库」**：绑定变量名不是 `DB`，或绑定后没有重新部署。
2. **分享链接里的域名不对**：链接使用访客当前访问的域名自动生成，若域名不对请检查 Cloudflare 的自定义域绑定与 DNS。
3. **未登录访客看不到文件**：检查「对未登录访客开放文件浏览」是否开启，以及「未登录访客根目录」下是否真的有文件（默认 `/文件分享`）。`n3.1 **用户看不到文件**：检查「用户根目录」设置；用户只能看到该目录及其子目录。
4. **忘记管理员密码**：在 D1 控制台依次执行
   `DELETE FROM bcd_admins;` 和 `DELETE FROM bcd_sessions;`，
   再访问站点，系统检测到没有任何管理员时会重新创建默认账号 `admin / admin123`（请立即改密）。
5. **导入备份失败**：单次导入文件上限 8 MB，且导入模式必须与备份文件的类别一致（例如「设置」的备份不能用「文件」模式导入）。
6. **下载不计数**：确认「统计下载次数」为开启；关闭后不再累加，历史数据保留。

## 九、安全建议

- 部署后第一时间修改默认总管理员密码。
- 站外分享链接由分享者自行提供，注意甄别；直链下载会 302 跳转到原地址，请勿用于侵权内容分发。
- 如需限制访客访问，可关闭「对访客开放文件浏览」，或在 Cloudflare 侧加 Access / WAF 规则。
